# Журнал изменений

Все значимые изменения Gamma документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект следует [Semantic Versioning](https://semver.org/lang/ru/spec/v2.0.0.html).

## [1.0] — 2026-10-11

Первый публичный релиз.

### Добавлено
- 12 встроенных пресетов цветовой температуры (1900K–7500K + особые режимы)
- Собственные пользовательские пресеты с описаниями и всплывающими подсказками
- Интерфейс на Tkinter: выбор монитора, RGB-регулировка гаммы, живой предпросмотр градиента
- CLI: применение по имени/ID, перечисление мониторов, циклическое переключение, `--restore` для автозапуска
- Независимая настройка гаммы и яркости для каждого монитора
- Автовосстановление настроек при входе в сессию (`autostart-enable.sh`)
- Локализация: русский и английский
- Установка через `install.sh` / `uninstall.sh` / `Makefile` и `.desktop`-файл
- Логирование в `gamma.log` для разбора проблем

### Требования
- Python 3.10+
- Сессия X11 с `xrandr` (Wayland не поддерживается)
