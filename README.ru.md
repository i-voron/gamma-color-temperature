# Gamma — Менеджер цветовой температуры

[English](README.md) | **Русский**

Простая утилита для **X11** для ручного управления пресетами цветовой температуры монитора. Написана на Python и Tkinter, не требует фоновых процессов и внешних зависимостей.

> ⚠️ **Важно:** Gamma работает **только на X11**. В Wayland утилита не функционирует, так как `xrandr` не имеет доступа к управлению гаммой. Для Wayland используйте Gammastep или встроенный Night Light.

## 🎯 Для кого Gamma?

**Gamma идеальна, если вы:**
- Используете **X11** (не Wayland)
- Предпочитаете **ручное управление** вместо автоматических переходов
- Хотите **минимум зависимостей** — только Python + xrandr
- Нуждаетесь в **портативном решении** без установки в систему
- Используете **i3wm, bspwm, AwesomeWM** и хотите назначить горячие клавиши
- Имеете **несколько разных мониторов**, которые нужно сбалансировать по цвету
- Цените **простоту** и прозрачность кода

**Gamma НЕ подойдёт, если вы:**
- Используете **Wayland** (нужен Gammastep или встроенный Night Light)
- Хотите **автоматическую смену** по времени суток (нужен Redshift/f.lux)
- Нуждаетесь в **геолокации** для автоматического расчёта заката/рассвета

## 🎯 Реальные преимущества

### Zero Configuration (Ноль настроек)
Программе не нужно знать, где вы находитесь, какое сейчас время суток и есть ли у вас интернет. Вы скачали её, запустили — и перед вами сразу готовые кнопки с понятной температурой (2700K, 3500K и т.д.). Не нужно искать координаты, писать `redshift.conf` или разбираться с geoclue.

### Независимая настройка мониторов
Если у вас несколько разных мониторов (например, IPS-экран ноутбука и внешний TN-монитор), они «из коробки» выдают совершенно разную картинку. Gamma позволяет:
- **Компенсировать плохую калибровку** — настроить RGB-гамму для каждого монитора так, чтобы белый цвет на них выглядел одинаково
- **Использовать раздельные пресеты** — основной монитор тёплый для чтения кода (3500K), второй в нейтральных тонах (5000K) для референсов
- **Сохранять сложную конфигурацию** в один JSON-файл, который не слетает при перезагрузке сессии

В отличие от Redshift, который применяет настройки глобально ко всей X-сессии, или Night Light, который работает по принципу «один ползунок на всё», Gamma даёт полный контроль над каждым дисплеем через GUI.

### Умное восстановление без демонов
Настройки гаммы для всех мониторов автоматически восстанавливаются при входе в систему. Программа делает это за долю секунды при старте сессии и сразу завершает работу, не оставаясь в оперативной памяти.

### Автоматизация в один клик
Вам не нужно вручную править `.xprofile` или файлы оконного менеджера. В комплекте идёт готовый скрипт `autostart-enable.sh`, который сам настроит автозапуск одной командой.

### Интерфейс для людей
В отличие от Redshift, где для создания пресетов нужно писать bash-скрипты-обёртки, в Gamma есть GUI на Tkinter, где можно в один клик сохранить текущий профиль, переименовать его или удалить.

### Портативность
Gamma — это готовый скрипт. Её не нужно собирать из исходников или подключать сторонние PPA-репозитории. Можно носить на флешке и запускать на любой X11-системе.

### Идеально для скриптов
Благодаря полноценному CLI программу удобно вешать на горячие клавиши оконного менеджера (i3wm, bspwm, AwesomeWM) для быстрого переключения режимов (например, `Super+F1` — день, `Super+F2` — ночь).

## ✨ Возможности

### Основные функции
- **Пресеты** — 12 встроенных пресетов (1900K–7500K + специальные режимы) + создание своих
- **Комментарии к пресетам** — описание назначения каждого пресета с подсказками при наведении
- **Быстрое избранное** — 5 слотов для часто используемых пресетов с цветовой индикацией; кнопка 🌐 применяет текущие значения ко всем мониторам сразу
- **Поддержка нескольких мониторов** — независимые настройки для каждого
- **CLI для горячих клавиш** — применение пресетов из терминала
- **Импорт/Экспорт** — обмен пресетами через JSON
- **Автозапуск** — восстановление настроек при входе в систему (one-shot, без демона)
- **Двуязычный интерфейс** — русский/английский
- **Бэкап конфига** — автоматическое сохранение `.bak`
- **Редактирование пресетов** — единая форма для изменения имени, комментария и RGB-значений пресета (с `ttk.Spinbox` для точного ввода значений 0.00–1.00)
- **Сброс гаммы** — кнопка быстрого возврата к нейтральному RGB(1.0, 1.0, 1.0) для текущего монитора

### Интерфейс и UX
- **Flat-дизайн** — современный плоский интерфейс без устаревших 3D-рамок
- **Автоопределение темы** — автоматическое переключение между тёмной и светлой темой системы
- **DPI scaling** — автоопределение HiDPI (через `GDK_SCALE`, `Xft.dpi` или физический DPI монитора через `xrandr`) с автоматическим масштабированием шрифтов и виджетов; выбранный масштаб сохраняется в config и может быть изменён в runtime через `Ctrl++`/`Ctrl+-`/`Ctrl+0`
- **Горячие клавиши GUI** — `Ctrl+S` (сохранить), `Ctrl+I`/`Ctrl+E` (импорт/экспорт), `Ctrl+F` (фокус на поиск), `Ctrl++`/`Ctrl+-`/`Ctrl+0` (масштаб UI), `Ctrl+Shift+A` (применить ко всем мониторам), `1`–`5` (слоты избранного), `Escape` (закрыть окно)
- **Цветные индикаторы каналов** — маленькие цветные квадраты R/G/B рядом со слайдерами для быстрой визуальной привязки
- **Утолщённый жёлоб слайдера** — увеличенная толщина полосы слайдера для удобного захвата мышью
- **Визуальные маркеры** — ★ для избранных пресетов, ▶ ◀ для активного
- **Подсветка активного пресета** — оранжевый текст в панели пресетов для текущего пресета
- **Тематизированные диалоги** — кастомные окна сообщений вместо стандартных messagebox
- **Нативные диалоги файлов** — через zenity (опционально, при наличии) для соответствия теме системы; без него используются встроенные диалоги tkinter
- **Tooltip с комментариями** — всплывающие подсказки с описанием пресетов
- **Цветные кнопки избранного** — каждая кнопка окрашена в цвет своего пресета

```bash
$ ./gamma.py --next
```

```bash
$ ./gamma.py --preset "6500K (Daylight)"
```

```bash
# Настроить внешний монитор
$ ./gamma.py --slot 3 --monitor HDMI-A-0

# Применить пресет ко ВСЕМ мониторам сразу
$ ./gamma.py --slot 1 --all

✅ Applied: 3500K (Warm Light) (RGB: 1.00, 0.83, 0.61) to monitor eDP
✅ Applied: 3500K (Warm Light) (RGB: 1.00, 0.83, 0.61) to monitor HDMI-A-0
```

### Восстановление при автозапуске

```bash
$ ./gamma.py --restore
⏳ Waiting 3s for monitors...
✅ eDP-1: 3500K (Warm) (RGB: 1.00, 0.83, 0.61)
✅ HDMI-A-0: 6500K (Daylight) (RGB: 1.00, 1.00, 1.00)
```

### Горячие клавиши (пример для i3wm)

В `~/.config/i3/config`:
```bash
bindsym $mod+F1 exec ~/bin/gamma/gamma.py --slot 1
bindsym $mod+F2 exec ~/bin/gamma/gamma.py --slot 2
bindsym $mod+F3 exec ~/bin/gamma/gamma.py --next
```

## 🚀 Установка

### Требования

- **X11** (не Wayland)
- Python 3.10+ (для built-in generics `list[X]`, `X | None` и `match/case`)
- `xrandr`
- `python3-tk` (или `python3-tkinter` / `tk` в зависимости от дистрибутива)
- `zenity` (опционально — для нативных диалогов импорта/экспорта в стиле системной темы; без него используются встроенные диалоги tkinter)

**Установка зависимостей на Debian/Ubuntu:**
```bash
sudo apt install python3 python3-tk xrandr  # zenity — опционально
```

**На Fedora/RHEL:**
```bash
sudo dnf install python3 python3-tkinter xrandr  # zenity — опционально
```

**На Arch Linux:**
```bash
sudo pacman -S python tk xorg-xrandr  # zenity — опционально
```

### Быстрая установка

```bash
cd ~/bin/gamma/
./install.sh
```

Скрипт `install.sh` выполняет:
1. **Проверка зависимостей** — `python3`, `xrandr`, `python3-tk` (если чего-то не хватает — подсказывает команду установки)
2. **Проверка файлов** — убеждается, что `gamma.py` рядом, делает его исполняемым (`chmod +x`)
3. **Создаёт `.desktop` файл** — `~/.local/share/applications/gamma.desktop` (Gamma появляется в меню приложений)
4. **Устанавливает иконку** — копирует `gamma.png` в `~/.local/share/icons/`
5. **Обновляет кэш** — `update-desktop-database` + `gtk-update-icon-cache`

> Не требует `sudo` — установка в домашнюю директорию (`~/.local/share/`). Если Gamma уже установлена, спросит подтверждение переустановки.

### Удаление

```bash
cd ~/bin/gamma/
./uninstall.sh
```

Скрипт `uninstall.sh` выполняет:
1. **Показывает список файлов** для удаления
2. **Запрашивает подтверждение** `[y/N]`
3. **Удаляет `.desktop` файл** — `~/.local/share/applications/gamma.desktop`
4. **Удаляет иконку** — `~/.local/share/icons/gamma.png`
5. **Обновляет кэш** приложений

> Настройки и пресеты (`gamma_config.json`) **не удаляются** — остаются в папке со скриптом на случай переустановки.

### Через Make

```bash
make install      # Установить
make uninstall    # Удалить
make run          # Запустить
```

## 🖥️ Использование

### Графический интерфейс

```bash
./gamma.py
```

**Интерфейс:**
- **Слева**: выбор монитора, слоты избранного с кнопкой 🌐 (применить ко всем), RGB-слайдеры с цветными индикаторами каналов, кнопки «Сохранить» и «Сброс», тестовая цветовая полоса
- **Справа**: панель пресетов с поиском и tooltip-подсказками
- **Контекстное меню** (правый клик на пресете): добавить в избранное, **изменить** (имя + комментарий + RGB через Spinbox), удалить
- **Тема**: автоматически определяется из системных настроек GTK
- **DPI scaling**: автоматически определяется HiDPI (через `GDK_SCALE`, `Xft.dpi` или физический DPI монитора), масштаб сохраняется в config и может быть изменён в runtime через `Ctrl++`/`Ctrl+-`/`Ctrl+0`

### Горячие клавиши GUI

| Комбинация | Действие |
|------------|----------|
| `Ctrl+S` | Сохранить текущие значения как новый пресет |
| `Ctrl+I` | Импорт пресетов из JSON |
| `Ctrl+E` | Экспорт пресетов в JSON |
| `Ctrl+F` | Фокус на поле поиска (с выделением текста) |
| `Ctrl++` | Увеличить масштаб UI на 0.25 (макс 3.0) |
| `Ctrl+-` | Уменьшить масштаб UI на 0.25 (мин 0.75) |
| `Ctrl+0` | Сбросить масштаб к авто-детекту DPI |
| `Ctrl+Shift+A` | Применить текущие значения ко всем мониторам |
| `1`–`5` | Активировать слот избранного (1–5) |
| `Escape` | Закрыть окно |

> Цифровые клавиши `1`–`5` работают и при фокусе в строке поиска. При открытом диалоговом окне (редактирование/сохранение пресета) горячие клавиши блокируются, чтобы не мешать вводу.

> Масштаб UI сохраняется в `gamma_config.json` (`ui_settings.ui_scale`) и применяется при следующем запуске на любом мониторе. `Ctrl+0` сбрасывает к авто-детекту — при следующем запуске масштаб будет заново определён из DPI текущего монитора и сохранён.

### Командная строка

```bash
./gamma.py --slot 1           # Применить слот 1
./gamma.py --next             # Следующий пресет
./gamma.py --preset 6500K     # По имени
./gamma.py --slot 1 --all     # Применить ко всем мониторам
./gamma.py --monitors         # Список мониторов
```

## 🔄 Автозапуск

Gamma может автоматически восстанавливать последние настройки гаммы при входе в систему. Это **one-shot** операция: программа запускается, применяет гамму ко всем мониторам и сразу завершается — никакого демона в памяти.

### Включить автозапуск

```bash
./autostart-enable.sh
```

Создаёт `~/.config/autostart/gamma-restore.desktop`, который запускает `gamma.py --restore` при входе в систему.

### Выключить автозапуск

```bash
./autostart-disable.sh
```

### Как это работает

1. При входе в систему DE/WM запускает `gamma.py --restore`
2. Программа определяет все подключенные мониторы
3. Для каждого монитора применяется сохранённая гамма (или последняя использованная)
4. Программа **завершает работу** — не остаётся в памяти
5. Настройки сохраняются для будущего использования

### Настройка задержки

Если внешние мониторы инициализируются медленно, отредактируйте созданный файл `~/.config/autostart/gamma-restore.desktop` и добавьте флаг `--delay`:

```ini
Exec=/home/username/bin/gamma/gamma.py --restore --delay 10
```

Или используйте переменную окружения для гибкости:

```bash
./gamma.py --restore --delay ${GAMMA_DELAY:-5}
```

## ⚙️ Конфигурация

`gamma_config.json`:
```json
{
  "ui_settings": {
    "language": "ru",
    "right_panel_visible": true,
    "window_geometry": "760x500+100+100"
  },
  "system_settings": {
    "monitor": "eDP-1",
    "monitor_gammas": {
      "eDP-1": [1.00, 0.83, 0.61],
      "HDMI-A-0": [1.00, 1.00, 1.00]
    },
    "last_rgb": [1.00, 0.83, 0.61]
  },
  "presets": [
    {
      "id": 1,
      "name": "3500K (Warm Light)",
      "rgb": [1.00, 0.83, 0.61],
      "comment": "Тёплый белый для работы при слабом освещении"
    }
  ],
  "favorites": [1, 2, 3, 4, 5]
}
```

**Поля пресета:**
- `id` — уникальный идентификатор
- `name` — отображаемое имя
- `rgb` — значения гаммы [R, G, B] в диапазоне 0.01–1.0
- `comment` — описание пресета (отображается в tooltip)

**Бэкап:** `.bak` создаётся автоматически при каждом сохранении.

> **Примечание:** Встроенные пресеты рассчитаны по колориметрической шкале Планка (алгоритм Таннера Хеллэнда). Если ваш монитор изначально искажает цвета, вы можете скорректировать коэффициенты в GUI и сохранить их в пользовательский JSON-профиль через "Импорт/Экспорт".

## 🛠️ Решение проблем

**Не работает:**
- Проверьте X11: `echo $XDG_SESSION_TYPE` (должно быть `x11`)
- Проверьте xrandr: `xrandr --version`
- Смотрите лог: `gamma.log`

**Внешний монитор не определяется:**
- Увеличьте задержку: `--delay 10`
- Проверьте: `xrandr --query`

**Конфиг повреждён:**
```bash
rm gamma_config.json  # Сброс к настройкам по умолчанию
```

**Диалоги файлов не соответствуют теме:**
- Установите zenity (опционально): `sudo apt install zenity`
- Gamma автоматически использует нативные диалоги при наличии zenity, иначе — встроенные диалоги tkinter

**Тёмная тема не определяется:**
- Проверьте GTK тему: `gsettings get org.gnome.desktop.interface gtk-theme`
- Или установите переменную: `export GTK_THEME=Adwaita-dark`
